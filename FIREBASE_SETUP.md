# 🔥 Firebase Setup Guide — Smart Expense & Budget Tracker

Complete step-by-step instructions to connect Firebase to your Flutter app.

---

## Step 1: Create a Firebase Project

1. Go to **[Firebase Console](https://console.firebase.google.com/)**
2. Click **"Add Project"**
3. Enter project name: `expense-tracker-app`
4. Disable Google Analytics (optional) → click **Create Project**
5. Wait for the project to be created → click **Continue**

---

## Step 2: Install Firebase CLI & FlutterFire CLI

Open your terminal and run:

```bash
# Install Firebase CLI (requires Node.js)
npm install -g firebase-tools

# Login to Firebase
firebase login

# Install FlutterFire CLI
dart pub global activate flutterfire_cli
```

---

## Step 3: Configure Firebase in Your Flutter Project

Run from your project root (`d:\23IT061\expense-tracker-app`):

```bash
flutterfire configure --project=YOUR_FIREBASE_PROJECT_ID
```

This will:
- Auto-detect platforms (Android, iOS, Web, Windows)
- Generate `firebase_options.dart` in `lib/`
- Create/update `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)

> Select **Android** and **Web** when prompted (or all platforms you need).

---

## Step 4: Enable Firebase Authentication

1. In **Firebase Console** → your project → left sidebar → **Build** → **Authentication**
2. Click **"Get Started"**
3. Under **Sign-in method** tab → click **Email/Password**
4. Toggle **Enable** → click **Save**

---

## Step 5: Set Up Cloud Firestore

1. In **Firebase Console** → **Build** → **Firestore Database**
2. Click **"Create database"**
3. Select **Start in test mode** (for development):
   ```
   allow read, write: if request.time < timestamp.date(2026, 6, 1);
   ```
4. Select your region (e.g., `asia-south1` for India) → click **Enable**

### Firestore Collections Structure

The app will automatically create these collections:

```
users/
  └── {userId}/
        ├── email: "user@example.com"
        ├── createdAt: timestamp
        ├── expenses/
        │     └── {expenseId}/
        │           ├── id: "uuid"
        │           ├── amount: 500.0
        │           ├── category: "Food"
        │           ├── date: "2026-04-03T09:00:00"
        │           ├── note: "Lunch"
        │           └── isSynced: true
        └── budgets/
              └── {month}/    (e.g., "2026-04")
                    ├── monthlyLimit: 10000.0
                    ├── spentAmount: 3500.0
                    └── month: "2026-04"
```

## Step 6: Update `main.dart` to Initialize Firebase

Replace the `main()` function in `lib/main.dart`:

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';  // auto-generated by flutterfire

void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  // Initialize Firebase
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  // Initialize Hive local storage
  await HiveService.init();

  runApp(const ExpenseTrackerApp());
}
```

---

## Step 7: Android-Specific Configuration

### 7a. Set minimum SDK version

Open `android/app/build.gradle` and set:

```gradle
android {
    defaultConfig {
        minSdkVersion 21   // Required for Firebase
    }
}
```

### 7b. Verify `google-services.json`

Ensure `android/app/google-services.json` exists (created by `flutterfire configure`).

### 7c. Add Google Services plugin (if not auto-added)

In `android/build.gradle`:
```gradle
buildscript {
    dependencies {
        classpath 'com.google.gms:google-services:4.4.0'
    }
}
```

In `android/app/build.gradle`:
```gradle
apply plugin: 'com.google.gms.google-services'
```

## Step 8: Firestore Security Rules (Production)

When moving to production, update Firestore rules:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users can only read/write their own data
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      
      match /expenses/{expenseId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
      
      match /budgets/{budgetId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```
